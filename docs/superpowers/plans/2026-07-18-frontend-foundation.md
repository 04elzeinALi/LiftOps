# Frontend Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the standalone React frontend's foundation — a separate app that logs a user in against the existing LiftOps Sanctum API and routes them to a placeholder dashboard based on their role (admin/driver/passenger), styled to match the approved mockup.

**Architecture:** A Vite + React (plain JS) app in a new sibling folder `c:\Users\Admin\liftops-frontend\`, using React Router for navigation, an Axios instance (with auth + 401 interceptors) wrapped by TanStack Query for data fetching, shadcn/ui + Tailwind v4 for components, and a CSS custom-property design system ported directly from the approved mockup. No real per-resource screens are built here — just the shell (login, routing, role-gated placeholder dashboards) that the next sub-project (Admin panel) builds on top of.

**Tech Stack:** React 19 (via Vite), react-router-dom, axios, @tanstack/react-query, Tailwind CSS v4, shadcn/ui, @fontsource (Barlow, Barlow Condensed, IBM Plex Mono).

## Global Constraints

- Plain JavaScript only — no TypeScript, no `.tsx`/`.ts` files.
- The frontend is a genuinely separate project/repo at `c:\Users\Admin\liftops-frontend\`, never inside `c:\Users\Admin\LiftOps\`.
- Auth token lives in `localStorage` under the key `"token"`.
- Design tokens (colors, fonts) must match the approved mockup exactly — see values in Task 3.
- No automated tests in this plan (explicitly out of scope per the design spec) — every task is verified by running the dev server and checking real behavior in the browser.
- Every `git commit` in Tasks 1–3 and 5–9 happens inside the `liftops-frontend` repo; Task 4's commit happens inside the `LiftOps` (backend) repo — these are two different repositories.

- [ ] **Step 1: Write the API client**

Create `c:\Users\Admin\liftops-frontend\src\api\client.js`:
```js
import axios from "axios";

const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL,
  headers: {
    Accept: "application/json",
  },
});

api.interceptors.request.use((config) => {
  const token = localStorage.getItem("token");
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

api.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem("token");
      if (window.location.pathname !== "/login") {
        window.location.href = "/login";
      }
    }
    return Promise.reject(error);
  }
);

export default api;
```

### Task 6: Build AuthContext

**Files:**
- Create: `c:\Users\Admin\liftops-frontend\src\auth\AuthContext.jsx`

**Interfaces:**
- Consumes: `api` default export from `@/api/client` (Task 5); backend routes `POST /login` (returns `{ message, data: { user, token } }`), `POST /logout`, `GET /user` (returns the user object directly)
- Produces: `AuthProvider` (component, wraps children), `useAuth()` hook returning `{ user, token, loading, login(email, password), logout() }` — `login` resolves to the logged-in user object; `logout` clears local state regardless of whether the network call succeeds

- [ ] **Step 1: Write AuthContext**

Create `c:\Users\Admin\liftops-frontend\src\auth\AuthContext.jsx`:
```jsx
import { createContext, useContext, useEffect, useState } from "react";
import api from "@/api/client";

const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const [token, setToken] = useState(() => localStorage.getItem("token"));
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    if (!token) {
      setLoading(false);
      return;
    }
    api
      .get("/user")
      .then((res) => setUser(res.data))
      .catch(() => {
        localStorage.removeItem("token");
        setToken(null);
        setUser(null);
      })
      .finally(() => setLoading(false));
  }, [token]);

  async function login(email, password) {
    const res = await api.post("/login", { email, password });
    const { token: newToken, user: loggedInUser } = res.data.data;
    localStorage.setItem("token", newToken);
    setToken(newToken);
    setUser(loggedInUser);
    return loggedInUser;
  }

  async function logout() {
    try {
      await api.post("/logout");
    } catch {
      // token may already be invalid server-side — clear local state regardless
    }
    localStorage.removeItem("token");
    setToken(null);
    setUser(null);
  }

  return (
    <AuthContext.Provider value={{ user, token, loading, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth() {
  return useContext(AuthContext);
}
```

import { Navigate, Outlet } from "react-router-dom";
import { useAuth } from "@/auth/AuthContext";

export default function ProtectedRoute({ allowedRoles }) {
  const { user, token, loading } = useAuth();

  if (loading) {
    return (
      <div className="grid h-screen place-items-center" style={{ color: "var(--text-muted)" }}>
        Loading…
      </div>
    );
  }

  if (!token || !user) {
    return <Navigate to="/login" replace />;
  }

  if (allowedRoles && !allowedRoles.includes(user.role)) {
    return <Navigate to={`/${user.role}`} replace />;
  }

  return <Outlet />;
}
